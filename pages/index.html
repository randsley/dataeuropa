dataeuropa

Python, Julia and R clients for data.europa.eu, the European open data portal: about 1.9 million dataset records from EU institutions and national and regional portals. Same verbs, same behaviour in all three languages. No API key needed.

Pythondataeuropa · requests, optional pandas JuliaDataEuropa.jl · HTTP, JSON3, DataFrames Rdataeuropa · httr2, jsonlite, base data frames

Search, then download

import dataeuropa as de

df = de.search_datasets("water quality", country="pt", format="CSV", limit=5)
dist = de.distributions(df.id[0])
de.download(dist.iloc[0], "data/")
using DataEuropa

df = search_datasets("water quality"; country="pt", format="CSV", limit=5)
dist = distributions(df.id[1])
download_distribution(dist[1, :], "data/")
library(dataeuropa)

df <- de_search_datasets("water quality", country = "pt", format = "CSV", limit = 5)
dist <- de_distributions(df$id[1])
de_download(dist[1, ], "data/")
