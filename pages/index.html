European open data, read straight into a data frame

Clients for data.europa.eu in Python, Julia and R. Search about 1.9 million dataset records from EU institutions and national portals, download files with checksum checks, and read tables and geodata. The functions have the same names in all three languages, and no API key is needed.

From a search to a table

Air-quality readings from Lisbon, in three steps. Each language uses the same functions; only the prefix changes.

  1. Find datasets: Portuguese air-quality data published as CSV

    Python
    hits = de.search_datasets('"air quality"', country="pt", format="CSV")
    Julia
    hits = search_datasets("\"air quality\""; country="pt", format="CSV")
    R
    hits <- de_search_datasets('"air quality"', country = "pt", format = "CSV")

  2. List the files of the Lisbon dataset, without services or web pages

    Python
    files = de.distributions("6689f1686e4bd9bc98ed011b", files_only=True)
    Julia
    files = distributions("6689f1686e4bd9bc98ed011b"; files_only=true)
    R
    files <- de_distributions("6689f1686e4bd9bc98ed011b", files_only = TRUE)

  3. Read the first quarter of 2024 into a data frame

    Python
    qa = de.load_distribution(files[files.title == "QA_2024_Q1"].iloc[0])
    Julia
    qa = load_distribution(files[findfirst(==("QA_2024_Q1"), files.title), :])
    R
    qa <- de_load_distribution(files[files$title == "QA_2024_Q1", ])

Install

Not yet on PyPI, the Julia registry or CRAN; install from GitHub for now.

Python
pip install "dataeuropa[pandas] @ git+https://github.com/randsley/dataeuropa#subdirectory=python"
Julia
using Pkg; Pkg.add(url="https://github.com/randsley/dataeuropa", subdir="julia")
R
remotes::install_github("randsley/dataeuropa", subdir = "r")

Then import dataeuropa as de, using DataEuropa or library(dataeuropa).

Worked examples

Complete tasks, the same in each language.

  • Air quality in Lisbon From a search to mean NO₂ per station, with the data's missing-value code and a minimum number of readings.
  • Who publishes air-quality data, and in what formats Counts and filter values without downloading any records.
  • Boundaries of Gelsenkirchen from a feature service The same layer through OGC API Features and WFS, with areas and reprojection.

Read them in Python, Julia or R.

Documentation

  • Python Package dataeuropa. Needs only requests; pandas, geopandas, openpyxl and pyarrow are optional.
  • Julia Package DataEuropa, built on HTTP, JSON3, DataFrames and CSV. GeoDataFrames, XLSX and Parquet2 are optional.
  • R Package dataeuropa, built on httr2 and jsonlite, returning base data frames. sf, readxl and arrow are optional.
